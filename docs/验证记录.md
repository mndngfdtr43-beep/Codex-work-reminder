# 验证记录

本记录区分软件测试与实际硬件验证。

| 检查 | 结果 |
|---|---|
| 软件测试 | 37 项通过：状态机、串口解析、重复事件过滤、前台保护、草稿保护、会话隔离、新会话与切换时的操作复核 |
| 板载灯固件 | 公开版源码编译通过：ESP32 core 3.3.12、NeoPixel 1.15.2；DIO、16MB Flash、GPIO48、1 颗 RGB LED；程序 304242 字节，静态内存 22320 字节 |
| 硬件通信 | 实际开发板握手及全部 8 种状态应答通过 |
| RGB 灯与 BOOT | 目视确认蓝色常亮，短按 BOOT 后变绿 |
| 停止与继续 | 已实测两轮 BOOT 停止、再次按键继续，Codex 界面均确认状态变化 |
| 自动跟随 | 实际切换到另一个会话后识别空闲，返回工作中的会话后恢复工作状态，无需重启 |
| 新建会话 | 已实测识别空白输入框和发送控件；首条草稿发送与转为运行态由软件测试覆盖，尚未单独实测新会话首次发送 |
| 已知现象 | 继续后界面刷新可能短暂无法识别输入框，随后自动恢复；不自动重试发送 |

纯软件测试不能替代所有板卡版本与 Codex 桌面版本上的实际验证。多窗口选择和异常断电场景未完成全面实物验收。
